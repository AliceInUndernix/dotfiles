1Sh = one-time Shift. Fn = hold for the function keys (layer 10). . ! ? , : type just the mark (for Shift see layer 1).
Yellow boxes are chords: press the keys under (or above) a box together. Two boxes with the same name are one chord, one key each: ` = " and ', Ctrl+Shift = Ctrl and Red. STmx = scratchpad with tmux (Super+`), Scr = scratchpad with a plain st (Super+n). Word = add a steno word (Super+y, steno -W): it closes once the outline is saved. Stky = pin the window on its tag, Shift+Stky on every tag (it floats, Next/Prev skip it). Susp = suspend (Super+Ctrl+Shift+z). Term = st (Super+Shift+u), Lock = slock (Super+Shift+o).
With Shift: Tag = move window there, Next/Prev = move window in stack, Shrk/Grow = move the border under the window up/down, Mon = send window to monitor,
Tmux = new tmux session. Ctrl + Tag = show that tag as well.
MDck = masterdeck (Super+e). Shift on any other key does nothing; Flt and Mono are on the number row. Tags count from each pinky: Tag1 right pinky, Tag6 left pinky, All (view all tags) on the left inner index key.
